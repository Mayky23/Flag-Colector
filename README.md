# 🚩 Flag Collector

🌐 **Live project:**  
https://mayky23.github.io/Flag-Colector/

**Flag Collector** is a personal project where I collect and document **flags obtained from cybersecurity challenges, vulnerable machines, and CTF-style labs**.

The goal of this project is to track my progress in **ethical hacking, penetration testing, and vulnerability exploitation**, while continuously improving my practical cybersecurity skills.

---

## 🎯 Purpose of the Project

This project acts as a **learning tracker and documentation platform** for cybersecurity practice.

It helps me:

- 📌 document solved challenges  
- 🚩 track captured flags  
- 🧠 review attack methodologies  
- 📚 reinforce practical hacking knowledge  
- 🗂 build a personal archive of solved labs  

---
